# 多维检索升级 · v0.2 · 2026-10-13

## 本次修复

原规则遇到已知的“人物 / 生日”就漏掉原句的光影和动作；只核对前八张会错过排在后面的目标；被核对的照片即使冲突也可能被整体提升。现修复条件保留、完整旧会话恢复和核对证据分层。

## 通用流程

1. Qwen3 将当前完整对话解析成开放词汇条件，每个条件保留中文、英文、用户原文证据、维度及必须 / 偏好 / 排除类型。没有为某张照片定制关键词。
2. SigLIP 对全句与各条件分别检索；综合条件联合匹配，亮度统计仅作光影线索的辅助依据。
3. 可选详细索引：Qwen3-VL 指令版逐张描述整体画面、光影、构图、视角、物体、人物、动作、颜色和文字；整体和各字段分别转为向量。依据内容指纹缓存，不同问题复用分析。
4. 候选核对按每条条件返回符合、不符合或无法判断及证据。明确符合优先；不确定保留；明确冲突靠后。可扩大到 24 / 48 张或全部当前候选，继续下一批。

详细索引不会移动或修改原图；未完成的图库仍可用基础图文检索。重启后已保存分析可复用，再次启动跳过内容未变且分析完成的图片。初次全库分析可能较慢，16GB 上建议先选小图库试跑。界面“全部候选”本版上限为 1000，超大图库仍需分页优化。
