# 结果筛选与移动端参考（2026-10-16）

## 本次网页实现

召回和排序仍保留完整候选池；“是否进入主结果”另设准入判断。不能把 RRF 相对名次、余弦相似度或 CORE yes/no logit 当作校准后的匹配概率，也不设通用的 0.5/0.8 阈值宣称符合。

四种状态：
- matched：必需条件逐项获得 matched，且没有内部矛盾或缓存事实冲突。只有偏好条件时至少一项有正向核对。
- unreviewed：尚未进行候选核对，即便检索得分很高也不直接视为符合。
- uncertain：有条件缺失、无法判断或核对结论与依据矛盾。
- not_matched：模型认为某必需条件不符，或数量/时间记录冲突。它仍然可能误判，因此只从主结果隐藏，允许复查。

主结果默认仅显示 matched，标为“较符合”，不声称绝对正确。其他候选通过独立开关查看，并显示各状态数量。无查询时正常浏览全库，演示库不套用真实图片核对准入。

“继续筛选”从未核对候选池选图，不依赖主结果中是否有未核对卡片；每批可选 6/12/24/64 张，可停止，逐张完成后更新主结果。现有自动核对预算保持有限，避免默认遍历数百张导致长时间等待。已完成的首批筛选不等于已筛完整个图库；页面同时显示当前候选规模、已核对数量，以及全库规模（候选未覆盖全库时）。不确定项可打开原图单独重查。

自动、手动和缓存结果使用同一个准入规则；新结果会重新计算状态，防止过期 matched 标志残留。没有符合结果时不拿前几名候选填满页面，也不把“没有已确认结果”写成“全库没有这样的照片”。原始照片和候选记录均不删除。

验证：新增准入、缺失条件、排除条件、软偏好、矛盾结果、重复核对状态更新等逻辑检查；前端用模拟照片验证默认筛选、候选保留和隐藏候选的继续筛选。未执行整库模型准确率测试。

## 手机端参考（调研，未实施）

### CLIP-Finder2：iOS 工程参考

https://github.com/fguzman82/CLIP-Finder2

作者项目使用 MobileCLIP、Core ML、Core Data，提供异步预测、批处理和模型性能分析入口。适合参考相册索引与缓存、异步预测、不同计算单元的测量。README 的固定大批量和实验 Turbo 模式不能直接照抄到不同内存和温度条件的手机；也不能把作者速度描述当成本项目实测。

其 README 对 MIT 的描述不构成 MobileCLIP 权重商业许可依据，仍以权重官方 LICENSE_MODELS 为准：
https://github.com/apple-aiml-research/ml-mobileclip/blob/main/LICENSE_MODELS

### Imprint：端侧调度与混合检索参考

https://github.com/bhavya-x/Imprint

作者公开的 Android 实现采用 SigLIP 图文向量、独立 OCR、脸部特征与混合排序，并考虑温度、电量和后台索引调度。可参考任务恢复、特征复用和多路证据设计。Android 的 ONNX/WorkManager 代码不能直接作为 iOS 实现，项目说明也未提供能换算到私人相册多条件 Precision/Recall 的证据。

### TinyCLIP：轻量编码器对照

https://github.com/wkcn/TinyCLIP

论文/代码研究通过蒸馏缩小 CLIP 编码器，适合用于速度与召回损失对照。它不是完整相册产品，也不能默认其所有权重支持中文、已完成 Core ML 转换或满足复杂关系筛选；具体权重许可另行确认。当前不下载、不替换桌面模型。

### 苹果 Core ML 压缩流程

https://apple.github.io/coremltools/docs-guides/source/opt-workflow.html

先以固定输入尺寸转换并测量原模型，再比较 8bit/调色板压缩；模型文件缩小不必然等价于推理变快。应同时记录查询延迟、每张索引时间、峰值内存、热降频，以及压缩前后的中文检索召回与最终结果精确率。

### 否定条件的已知局限

https://github.com/m1k2zoo/negbench
https://arxiv.org/abs/2501.09425

NegBench（CVPR 2025）表明视觉语言检索模型在否定条件上存在局限，不能仅凭 CLIP 相似度宣称“不要人群”“不是红色”等限制已可靠满足。复杂限制要单独检查、允许拒答/暂不展示，并评估漏检率。

## 后续手机路线

先以已核对的桌面方案确认产品行为；手机版使用小型多语言图文编码器一次建索引、以后只编码查询。简单对象/场景先快速召回，严格人数/否定/位置关系再对少量候选按需核对。OCR 独立辅助，不逐张调用大模型生成长描述作为首次使用门槛。

准入门槛应在独立样本上校准：分别衡量主结果 Precision、符合照片 Recall、无匹配查询的错误展示率和 P50/P95 首屏延迟。高 Precision 与高 Recall 不能因页面只剩几张就视为同时达到。更小的模型、量化和减少核对次数都要报告相应损失；目前不能承诺 95% 或一万张一分钟。
