## 使用

1. 打开 http://127.0.0.1:8765/，保持 Ollama 运行。
2. 添加照片文件夹，建立基础视觉索引。已有完整索引无需重做。
3. 可点「详细画面索引」，逐张丰富光影、构图、视角和动作等信息。初次较慢，可暂停和续建。
4. 输入中文或英文描述；继续补充会更新当前条件并检索全库。
5. 有明确条件时会自动核对，主要结果只显示已核对符合的照片。可展开待核对 / 无法判断的候选。
6. 选择每批 8 / 24 / 48 张或全部候选，点「扩大范围仔细核对」继续下一批。

模型安装后无需 API Key，无按次数费用，照片和索引保留在本机。演示练习册依然使用预设标签。
