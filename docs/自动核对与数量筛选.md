# 自动核对与数量筛选 · v0.3 · 2026-10-13

## 问题与改动

“只有一个人与车合拍”此前虽然出现在条件中，却仍靠图文相似度排序，未核对的多人照片直接出现在主要网格。上次暗光任务的成功不能证明一般检索准确率。

当前链路：完整条件解析 → 全库向量召回 → 当前候选池数量初筛 → 看图逐项核对 → 主要结果仅展示模型核对符合的照片。候选池当前上限 1000 张；数量初筛覆盖这个池，再从未排除的候选中看图核对最多 48 张，找到 6 张符合后停止。可暂停，手动扩大范围继续。未核对、无法判断与明确不符有不同状态，不能混称匹配。

## 可复用证据

- 数量条件不是关键词相似度：保存实体、eq / gte / lte 和整数要求；“只有一个人”是 person eq 1。
- YOLO26 nano 用原图、1280 输入和 CPU 检测，记录框与模型分数。高于 0.4 的目标仅证明数量下限，不证明不存在其他目标。0.15 至 0.4 的独立疑似目标不能证明数量，但与看图计数冲突时必须标记未知。重叠的低分框不重复计数。
- 下限已证明不符时，跳过昂贵看图调用；其余由 Qwen 计数和逐项核对。数量与看图结论有冲突时，不提升为已确认。
- 目标检测按照片内容指纹和模型版本缓存，数量事实按实体缓存，核对按完整条件缓存。换问法可以复用检测，却不能复用另一组条件的结论。
- 模型与 Python 依赖均本地运行；检测器关闭同步和自动安装、使用离线模式。照片不上传。YOLO 代码与模型采用 AGPL-3.0，许可来源保留于官方链接。

## 验证范围

- 20 项回归检查：明确数量、未知不冒充零、数量事实复用、可能的背景人物阻止假单人确认、自动任务取消，以及正确照片在第 101 个候选时通过数量初筛进入核对。
- 真实截图中的 DSC00218、DSC00244、DSC02010 已得到多个人物的位置证据；不应进入单人查询的主要结果。相同文件名可能对应不同照片，检查用资源 ID 与内容指纹。
- 少量真实照片与网页自动流程验证，不能代表完整图库准确率。旧报告是当时版本结果，不能当成当前质量认证。

## 仍有局限

遮挡、背影、极小人物、海报中人物、反射、相似物体都会导致误检或漏检。小型看图模型也可能给出错误证据。保留不确定是为了减少错误确认，代价是主要结果可能更少；可查看未知候选继续找。数量之外的细微构图、动作与关系仍需独立验收，不能因为数量链路通过就宣称全部维度可靠。

建议真实验收先准备至少 30 条跨类别任务，每条人工标记符合 / 不符合 / 不确定。除 Hit@5 和 Recall@20，还记录主要结果的条件通过率和明显矛盾率；只有一个人的结果出现多人，应单独算作错误。当前尚未测得整体指标。
